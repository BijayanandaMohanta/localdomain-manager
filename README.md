# LocalDomain Manager

LocalDomain Manager is a PHP utility for managing local Apache/XAMPP PHP and Laravel projects using custom local domains.

## Features

- Helps configure local domains for PHP/Laravel projects
- Intended for Apache + XAMPP development setups
- Simple PHP-based workflow

## Repository

This project is available in the GitHub repository `BijayanandaMohanta/localdomain-manager`.

## Getting Started

1. Clone or download the repository.
2. Place it in your local development environment.
3. Configure Apache/XAMPP and your hosts/domain setup as needed.
4. Run or integrate `localdomain.php` for your project workflow.

- `localdomain.php` — main PHP script
